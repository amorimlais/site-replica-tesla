🚘 Tesla Website Replica

Projeto de reprodução visual de uma página do site da Tesla, desenvolvido durante uma imersão de programação com Rodolfo Mori.

O objetivo foi colocar em prática conhecimentos de desenvolvimento front-end, explorando a estruturação de páginas web, estilização de interfaces e implementação de interações com JavaScript.

🎯 Sobre o projeto

Este projeto consiste em uma réplica inspirada no site da Tesla, com foco na prática de desenvolvimento web e na reprodução de elementos visuais de uma interface real.

A experiência permitiu exercitar habilidades de construção de páginas, organização de código e aplicação dos conceitos estudados durante a imersão.

🛠️ Tecnologias utilizadas

HTML5 — estruturação da página.

CSS3 — estilização e construção do layout.

JavaScript — implementação de interações e comportamentos da interface.

📚 Aprendizados

Estruturação de páginas web com HTML.

Estilização de interfaces utilizando CSS.

Aplicação de JavaScript no desenvolvimento front-end.

Prática de reprodução de interfaces existentes.

Desenvolvimento de habilidades técnicas durante uma imersão de programação.
